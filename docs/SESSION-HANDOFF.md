### 2.2 Slack

현재 Codex에 연결된 Slack은 사용자가 원하는 부트캠프/팀 Slack이 아니다.

확인된 연결:

- 워크스페이스명: 개인 Slack 워크스페이스
- 확인된 채널: 개인 채널 3개

파일 검색 결과:

- `after:2026-07-01`, 파일만 검색: 0건
- `기획서 after:2026-07-01`, 파일만 검색: 0건

따라서 Slack 파일이 없는 것이 아니라 **잘못된 워크스페이스가 연결된 상태**로 판단한다. 다음 세션에서 같은 검색을 반복하지 말고 먼저 연결 워크스페이스를 확인해야 한다.

Slack 커넥터에서 확인된 기능 제약:

- 파일 검색 결과는 한 번에 최대 20개이며 cursor로 페이지네이션한다.
- `file_id`를 얻으면 `slack_read_file`로 읽을 수 있다.
- `slack_read_file`은 파일당 10MB 제한이 있다.
- 텍스트 파일은 본문을 읽을 수 있지만, 바이너리는 파일 참조로 반환될 수 있어 로컬 저장 여부를 별도로 검증해야 한다.

Chrome의 로그인된 Slack 화면을 이용하는 대안도 검토했으나, 이번 세션에서는 브라우저 제어 런타임이 열리지 않아 실제 UI 조작이나 다운로드를 하지 못했다.

## 3. Slack 전체 다운로드에 관한 결론

Slack 공식 데이터 내보내기는 일반적인 JSON 내보내기에서 원본 파일을 ZIP에 넣어 주지 않고, 메시지와 파일 링크를 제공한다.

- Free/Pro/Business+의 공개 채널 내보내기: 소유자·관리자 권한 필요
- 일반 JSON 내보내기: 원본 파일이 아니라 파일 링크 포함
- Free 플랜: 최근 90일 파일 링크만 내보낼 수 있음
- Enterprise의 일부 단일 사용자 TXT 내보내기 등 예외에서는 파일 폴더가 포함될 수 있음

공식 문서:

- <https://slack.com/help/articles/201658943-Export-your-workspace-data>
- <https://slack.com/help/articles/220556107-How-to-read-Slack-data-exports>

현실적인 수집 경로:

1. Codex Slack 연결을 실제 부트캠프/팀 워크스페이스로 다시 인증한다.
2. 파일 검색을 페이지네이션하여 전체 인벤토리를 만든다.
3. 접근 가능한 파일을 하나씩 읽거나 내려받는다.
4. 커넥터가 로컬 바이너리 저장을 지원하지 않으면 로그인된 Slack UI에서 개별 다운로드한다.
5. 워크스페이스 소유자 권한이 있다면 Slack 내보내기 ZIP도 받아 파일 링크 누락 여부를 대조한다.

브라우저 쿠키·세션 저장소를 직접 추출하거나 우회해서는 안 된다.

## 4. 공개 범위와 웹사이트 방향

2026-07-25 사용자가 이번 대화에서 제공한 문서 내용은 공개해도 된다고 확인했다. 단, 개인 이름은 공개 문서와 화면에서 제거한다.

- 공개 가능: 사용자가 제공한 아이디어 내용, 문서명, 기술 내용, 익명화한 판정 정보
- 공개 제외: 개인 실명, 개인을 직접 식별할 수 있는 계정·워크스페이스 정보
- 이후 새로 수집하는 자료: 이번 허용 범위에 포함되는지 다시 확인

`Killed by Google`에서 가져올 핵심 구조:

- 아이디어별 묘비 카드

- 원문 또는 근거 링크

사람을 공격하는 기록이 되지 않도록 `누가 죽였는가`보다 `왜 중단됐는가`를 중심으로 기록한다.

## 9. 작업 시 주의사항

- 현재 루트 Git 저장소는 아직 커밋이 없고 대부분 파일이 미추적 상태다.
- `아이디어-공동묘지`는 별도의 Git 저장소이므로 이 디렉터리 안에서만 커밋한다.
- `.DS_Store`, `.codex/`, `.serena/`, 기존 프로젝트 파일을 건드리지 않는다.
- `보드게임 플레이 플랫폼`과 `bamsongi-club/albam-mate`는 현재 최종 프로젝트 자료다. 새 아카이브 사이트와 섞지 않는다.
- 과거 `검은 항구` 자료는 폐기가 아니라 역사 자료로 취급하되, 현재 알밤메이트 요구사항의 기준으로 사용하지 않는다.
- 파일을 stage하거나 commit하라는 요청이 없는 한 Git 상태를 변경하지 않는다.
