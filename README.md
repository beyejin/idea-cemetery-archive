# 아이디어 공동묘지

중단된 팀 아이디어의 이유와 배움을 익명화해 기록하는 React 아카이브입니다.

- 공개 사이트: https://beyejin.github.io/idea-cemetery-archive/
- 소스 브랜치: `main`
- 배포 브랜치: `gh-pages`

## 로컬 실행

```bash
npm ci
npm run dev
```

## 검증

```bash
npm run test:run
npm run build
```

수정 사항은 별도 브랜치에서 작업한 뒤 `main` 브랜치로 Pull Request를 보내주세요. Notion 원문, 공개 동의를 확인하지 않은 개인 이름, 비공개 URL과 첨부파일은 저장소에 추가하지 않습니다.
