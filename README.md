# 아이디어 공동묘지

중단된 팀 아이디어의 이유, 배움, 판정자와 제공 원문을 공개하는 React 아카이브입니다.

- 공개 사이트: https://beyejin.github.io/idea-cemetery-archive/
- 소스 브랜치: `main`
- 배포 브랜치: `gh-pages`

## 로컬 실행

```bash
npm ci
npm run dev
```

## 검증

```bash
npm run test:run
npm run build
```

팀 작업 절차는 [CONTRIBUTING.md](CONTRIBUTING.md)를 따릅니다. 사용자가 제공한 아이디어 원문과 실명은 공개할 수 있지만 비밀번호, 인증 토큰, 세션 정보는 저장소에 추가하지 않습니다.
